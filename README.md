# PM Networks Apps für Home Assistant

App-Repository (ehemals „Add-ons“) für Home Assistant OS und Supervised.

## Enthaltene Apps

| App | Beschreibung |
| --- | --- |
| [PM Klima Studio](pm_klima_studio/) | Heizplan-Editor, Klima-Auswertungen und Wochenbericht für die Integration PM Klima. |

## Installation

[![Repository in Home Assistant hinzufügen](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FD0GC%2Fha-pm-networks-apps)

Oder manuell:

1. Einstellungen → Apps → App-Store öffnen.
2. Menü (drei Punkte) → Repositories.
3. `https://github.com/D0GC/ha-pm-networks-apps` eintragen und hinzufügen.
4. „PM Klima Studio“ auswählen und installieren. Das Image wird lokal gebaut; das dauert auf einem Raspberry Pi einige Minuten.

Updates erscheinen danach wie gewohnt unter Einstellungen → System → Updates.
